## MSVC x64 RTTI 布局（读取用）

| 符号 | 偏移 | 含义 |
|---|---|---|
| ??_R3 | +0x08 | numBaseClasses |
| ??_R3 | +0x0C | pBaseClassArray |
| ??_R2[0] | | 自身 |
| ??_R1A@ | +0x00 | pTypeDescriptor |
| TypeDescriptor 名字 | +0x10 | 类名 |
| ??_R4 | +0x00 | signature（须 == 1） |
| ??_R4 | +0x04 | offset |
| ??_R4 | +0x0C | pTypeDescriptor |
| ??_R4 | +0x10 | pClassHierarchyDescriptor |

    vftable - 8 处存着它自己的 COL 指针
