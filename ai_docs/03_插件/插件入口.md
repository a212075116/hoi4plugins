# 插件入口

> 源码：src/plugin/plugin_main.c
> 产物：hoi4_mod_plugin.dll

## 加载方式

**不被游戏直接加载**，由载体用绝对路径 LoadLibrary 加载。
因此它**不需要转发任何导出**。

## 启动流程

    DllMain(DLL_PROCESS_ATTACH)
      -> DisableThreadLibraryCalls(h)
      -> CreateThread(PluginThread)

    PluginThread:
      1. 轮询 (最多 300 次 x 200ms) 等 *(hoi4.exe + 0x332F260) 非 NULL
         —— 这就是"游戏状态已建立"的硬信号, 不掐表
      2. VerifyClassStructure()
      3. Camera_RegisterCommands()
      4. 循环扫 CGameState 已知类数组, 命中即报

## 关键设计：为什么不用"等 N 秒"

CGameState 全局指针由 NULL 变非空，是**游戏自己给出的**准确时点。
掐表等时间会在慢机器上失败、在快机器上浪费。

## 为什么不在 DllMain 里直接建线程

见 ai_docs/02_载体/CRT时序问题.md。同样的原因，插件也不能在 DllMain 里做重活。
