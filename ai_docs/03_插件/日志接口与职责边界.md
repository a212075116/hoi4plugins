# 日志接口与职责边界

2026-10-14，第十一批行为保持整理；只统一声明，不更改日志实现。

## 两层职责

| Interface | 位置 | 职责 |
|---|---|---|
| `void Plugin_Log(const char* fmt, ...);` | `src/plugin/SDK_RVA/common/plugin_log.h` | 插件模块提交一条格式化日志，不选择文件路径 |
| `void Log_AppendV(const char* path, const char* format, va_list arguments);` | 已有 `src/plugin/SDK_RVA/common/log.h` | 格式化并同步追加到调用方指定路径 |

`Plugin_Log` 实现仍在 `src/plugin/plugin_main.c`，选择现有载体相关日志路径，并负责 `va_start/va_end`。
`Log_AppendV` 实现仍在 `src/plugin/SDK_RVA/common/log.c`。
console的默认日志入口仍使用自己的路径，未被重定向到插件日志。

新增头文件只包含一个variadic声明，不依赖Windows、载体定义、对象布局或底层 `va_list` 接口。
17个现有C调用模块由本地手写extern改为包含该头文件；实现方也包含它，由编译器检查类型一致性。
不新增转发函数、宏包装、日志线程、队列、锁或另一套输出系统。
目前没有C++调用方；本批不声称新增了跨语言Interface。

## 保持的行为

- 插件/console各自的日志文件路径、时间戳与CRLF不变。
- 消息缓冲2048字节、输出行2304字节以及消息溢出丢弃策略不变。
- 追加模式、读写共享标志、写入与关闭顺序不变。
- 打开/写入失败处理不变，不新增目录创建或重试。
- 原有调用线程、同步写入、调用位置及格式串不变。
- 不在此处处理外部控制台显示配色、滚轮、Tab补全或IPC。
