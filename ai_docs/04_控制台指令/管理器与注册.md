# 命令管理器与注册

> 依据：IDA 静态分析 + 运行时实测
> 源码：src/plugin/SDK_RVA/console/console_cmd.c 的 ConsoleCmd_RegisterAll

## 全局槽

| 符号 | RVA | 含义 |
|---|---|---|
| qword_1435E1A80 | 0x35E1A80 | **命令管理器全局槽**（104 处引用） |

## 管理器布局

| 偏移 | 类型 | 含义 |
|---|---|---|
| +0x00 | CmdEntry* | data（表项数组） |
| +0x08 | int | capacity |
| +0x0C | int | **count** |
| +0x10 | void* | allocator（有虚表） |
| +0x50 | ? | 另有成员（未查明） |

由 sub_1424B4920 与 sub_1424B5CC0 两处**独立**证实。

## 相关函数

| 函数 | RVA | 作用 |
|---|---|---|
| sub_1424B4920 | 0x24B4920 | **合并命令表**：同名 stricmp 覆盖 / 新名追加 |
| sub_1424B4C40 | 0x24B4C40 | 管理器初始化 |
| sub_1424B5CC0 | 0x24B5CC0 | 按名字查命令 |
| sub_140231E20 | 0x231E20 | 在指定下标批量插入（**会先把表清零，别用于运行时追加**） |
| sub_14022AD20 | 0x22AD20 | 拷贝一个表项 |
| sub_140129CA0 | 0x129CA0 | std::string::assign（写长串） |

## 注册流程

    1. 读 *(hoi4.exe + 0x35E1A80)
    2. 若为 NULL -> 调 sub_1424B4C40() 初始化
    3. 逐条自检字符串长度
    4. 填 CmdEntry，塞进一个本地 CmdTable {data, capacity, count}
    5. 调 sub_1424B4920(manager, &table)
