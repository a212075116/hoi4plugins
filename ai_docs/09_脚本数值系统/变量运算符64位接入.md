# 四个算术运算符接入 64 位 (add / subtract / multiply / divide)

> 状态: **加减乘除已实现并实测通过。** 记录时间 2026-10-11 19:22:29
> 依据: 插件运行日志 + IDA 反编译 + effect map 遍历。

## 一、hook 目标 (静态反编译 + 运行期探针双重确认)

```
add_to_variable        0x14034C760   原始语义 *v6 += v8;
subtract_from_variable 0x140366BC0   原始语义 *v6 -= v8;
multiply_variable      0x14035B9E0   原始语义 v7 = *v6 * v9; *v6 = v7 / 100000;
divide_variable        0x140355C70   原始语义 if(v8) *v6 = 100000 * *v6 / v8; else *v6 = 0;
```

四个执行体的变量槽都在实例 `+88`、参数都在 `+296` (modulo 例外, 见另一篇)。

## 二、detour 的分派顺序 (性能关键)

```
1) 读实例 +505 的 marker -> 命中我们自己的 effect 分支则走现有逻辑
2) 否则只读 +200 的变量名, 查 64 位登记表 (纯内存比较, 零副作用)
     不在表里 -> 立刻转原版执行体
     在表里   -> 走 64 位运算, 原版执行体完全不执行
3) 原函数指针为空时返回 0
```

**为什么必须做廉价过滤**: 游戏内部 (历史/经济/AI) 会高频调用这些 effect,
热点路径上做任何重活 (查槽、解析参数) 都会出问题。第一版就是因为在 hook 里
调用了本地化上下文的函数导致崩溃 (见第四节)。

## 三、64 位运算的定点换算

```
当前值 raw = vInt x 100000 + vFrac     (从三分量读出)
操作数 raw = 参数值 (引擎已给定点 raw, 或我们自己按三分量读)

加减: 分别对整数/小数段运算后归一化 (小数满 100000 进 1, 不足借位)
乘法: rawProduct = (rawA x rawB) / 100000   -> 再拆整数/小数
除法: rawQuot    = (rawA x 100000) / rawB   -> 再拆整数/小数
      除数为 0 时保持原值并记日志
      128 位中间量 (MSVC _umul128) 避免溢出
```

**乘除必须做两次缩放**: `lo / 100000` 得到的仍是定点 raw, 不是整数部分。
直接当整数用会让结果放大 10 万倍 (实测 100 x 3 得到 30000000)。

## 四、操作数参数描述的结构 (关键发现, 后端起大作用)

操作数 (`value`) 的描述在 effect 实例 `+296` 处:

```
+0x00  指针 (vtable)
+0x08  标志位; 字节 +0x09 = 1 -> 常量; = 0 -> 变量/表达式
+0x40  常量值 (定点 raw, 例如字面量 7 时 = 700000)
+0x70  变量名 (std::string SSO 缓冲)
+0x80  size (名字字节数)
+0x88  capacity (15 = SSO 内联)
```

实测对照:

```
字面量 7:      +08 = 0x0101      +70 = 0
64位变量 ry:   +08 = 0x0001      +70 = 0x7972   -> 'r','y'
32位变量 rz:   +08 = 0x0001      +70 = 0x7A72   -> 'r','z'
```

**为什么必须自己读变量名**: 我们的存储把小数放在独立分量 `_f` 里,
而游戏的参数求值器只读主槽, 所以 `value = pz` (pz = 2.5) 只会给出 2。
自己拿到名字后按三分量读, 才能得到完整的 2.5。

实测修复效果:

```
VN v3=2762.5    1105 x 2.5      (修复前得到 2210)
VN v4=276.25    2762.5 / 10
PD b=109.5      107 + 2.5       (修复前得到 109)
PD c=113        109.5 + 3.5
```

## 五、两个致命坑 (都已修正, 记录以防重犯)

### 5.1 不能在 effect 的 hook 里调用本地化上下文的函数

`Var64_LangResolveSlotValue` 要求 `ctx` 是本地化上下文, 在 effect 作用域里调用
会**直接崩溃** (实测崩溃目录 `crashes/hoi4_20261011_171531`, 发生在进图
`Resetting game` 之后)。替代方案: 用实例自身的 `Var64_ResolveAddressByName`。

### 5.2 乘除的定点缩放不能少一层

见第三节。`lo / 100000` 是定点 raw 而非整数部分。
