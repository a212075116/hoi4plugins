# 已知问题

按"是否已解决"分组。未解决的必须留在这里，不能假装不存在。

## 已解决

| 问题 | 症状 | 处理 |
|---|---|---|
| 载体链接失败 | `LNK2001 TBB_runtime_interface_version` 等 11 个 | 用 `lib /def:` 先出 .exp 再链接，见 `构建方式.md` |
| 源码中文字符串 | `C4819` + `C2001 常量中有换行符` | 源码全英文 |
| 命令表项越界写 | 游戏崩溃（`0xC0000409`） | `FillCStr` / `SetMsg` 硬截断 15 字符 + 编译期断言 |
| 无参调用崩溃 | 只敲命令名回车即崩 | `SetMsg` 放行到 127 字符，消息 43 字符写穿结构 |
| 参数读不到 | `haveArg=0` | `CmdArgs.data` 是 `CmdString*`，不是二级指针 |

## 未解决

### 1. 命令表项的四个字段语义未知

`CmdEntry` 的 `+0x04`、`+0x70`、`+0x78`、`+0x84` 在构造时只写 0，
运行时读到的值（尤其 `+0x00` 的 flag）与 0/1 不符，说明游戏在注册后还会改写它们。
目前一律填 0，实测可用。**未查明含义。**

### 2. `cmake` 未提供

工程只有 `.sln` / `.vcxproj`。若要在 CI 或非 Windows 上构建，需要另加 CMake。
**当前没有这个需求，未做。**

### 3. Debug 配置未实测

`Debug|x64` 已写进工程，但只验证过 `Release|x64`。
Debug 版会链接调试 CRT，与游戏的静态 CRT 交互方式可能不同，**未验证**。

### 4. 探针脚本未做版本约束

`test/` 里的脚本大量硬编码了 RVA。游戏版本一变，这些数字全部作废。
**没有加版本校验。**
