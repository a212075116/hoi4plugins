## 未解决

### 1. 命令表项的四个字段语义未知

`CmdEntry` 的 `+0x04`、`+0x70`、`+0x78`、`+0x84` 在构造时只写 0，
运行时读到的值（尤其 `+0x00` 的 flag）与 0/1 不符，说明游戏在注册后还会改写它们。
目前一律填 0，实测可用。**未查明含义。**

### 2. `cmake` 未提供

工程只有 `.sln` / `.vcxproj`。若要在 CI 或非 Windows 上构建，需要另加 CMake。
**当前没有这个需求，未做。**

### 3. Debug 配置未实测

`Debug|x64` 已写进工程，但只验证过 `Release|x64`。
Debug 版会链接调试 CRT，与游戏的静态 CRT 交互方式可能不同，**未验证**。

### 4. 探针脚本未做版本约束

`test/` 里的脚本大量硬编码了 RVA。游戏版本变化必须重新核对，不能默认沿用。
**没有加版本校验。**
