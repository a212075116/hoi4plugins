# 脚本注册基础绑定：第二轮

2026-10-14，Effect/Trigger注册基础已接入统一适配器；不是所有脚本业务已跨版本可用。

## 实际迁移

四种模板：CAddStabilityEffect、CAlwaysTrigger、CHasStabilityTrigger、CCheckVariable。
通过RTTI定位主虚表及CEffectEntry/CTriggerEntry入口表；入口表只有两个方法，不能套用摄像机的四项过滤。
factory从入口槽1恢复，parse/eval从声明的模板槽恢复；同名多个主表、坏槽、loaded COL/指针/代码变化均拒绝。
factory必须满足已支持prologue、对象大小296/96/304/544、直接分配调用和派生虚表写入形式；四factory必须使用同一分配器。
不调用factory来探测，不从allocator+固定距离猜free，也不以模板名字证明任意新版ABI。

恢复20个表/方法字段和1个公共allocator；其他22个函数/数据端点及static token count移入本地registry资料。
Effect/Trigger业务不再硬填这些注册/参数/tooltip入口RVA；Var64共享参数读的两处调用也改为统一绑定并增加就绪检查。
Game/CRT分配器、构造/析构、scope、参数布局、变量存储和运算不重设计。Effect tooltip F1仍未证明所有权，本轮没有增加free。

## 资料和启用边界

游戏根hoi4plugins/bindings/<SHA>.registry，与摄像机.profile独立。启动加载，不热重载。
schema=1、contract=registry_v1、image_sha256、runtime_registration和static_token_count，加22个固定符号key。
函数为RVA:16字节小写hex指纹，验证执行节、file/loaded code与指纹；数据验证声明节和完整范围。
alloc不接受手填，由factory调用推导；模板表/工厂/parse/eval不在资料中手填。
字段数量/编码/重复key/未知key/整数溢出/未批准/坏指纹全部拒绝；完整成功后一次发布，失败不留部分可用地址。
资料是受信任的ABI审核声明，不是“地址在合法节里就自动证明函数语义”。尤其map地址、token count、allocator/free合同仍需审核。

资料未通过时整组Effect/Trigger及关联Var64脚本hook/语言桥注册跳过，不先用旧RVA注册后再显示错误。
摄像机只读及无关的已知构建功能不因此关闭；script.bindings和各注册组在独立功能日志中给原因。
整个未知构建仍受第一轮业务安全门约束：基础绑定验证不等于全部旧业务回调已迁移，不通过配置绕过全局门。
当前增加只读诊断命令plugin_script_bindings（已知构建的现有单人执行通道），显示四表、allocator和token count。

## 迁移工具不是自动批准器

工具migrate_script_bindings.py用RTTI/入口及factory恢复模板，对普通函数生成有限指令模式。
只屏蔽RIP-relative、分支位移及PE relocation字节，保留字段/对象大小等普通立即数；歧义或缺失不选第一个。
同SHA复用已审核资料；不同SHA输出runtime_registration=0，数据根和static token count不按整体delta猜。
对本地backup实际得到21个自动模板/allocator字段、13个普通函数唯一候选、9个未解决项；token count还需审核。
唯一字节候选不是ABI证明，签名可能随优化改变或落在错误语义位置，必须结合xref/调用关系及受控验收。

## 验证范围

实际C++绑定器在当前映像及重定位受控映像23检查通过；backup离线5检查，四模板/allocation均恢复。
当前生产游戏Bool触发器yes/no、typed half比较、变量块比较、64/vanilla切换、原版算术ROOT操作数及摄像机通过。
Bool24、typed29、scalar27268、Array注册4100、启动521场景、tooltip44及既有camera13的受控测试通过。
tooltip44仍只证明拥有/借用模型行为，不证明实际游戏泄漏或free合同。
实测中不存在的multiply_variable64是测试输入错误，已保留；应使用原版multiply_variable的64拦截路径或已定义的操作。
custom add_to_variable64 + ROOT在旧/新均得到12而非12.5，是保留的旧路径限制，不当作通过；分组输入中原版add_to_variable + ROOT旧/新均得到12.5。独立串行eval旧版曾重放不同语义，未归因，分组对照另存，不抹掉观察。
第二映像未启动，不宣称跨两版游戏实机；当前源码及DLL回滚、完整证据见[测试说明](../../test/docs/script_bindings.md)。
