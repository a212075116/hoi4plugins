# 原生摄像机适配与功能状态

2026-10-14，已接入生产插件。范围为摄像机只读闭环、启动安全门、本地资料及统一状态；不是全项目自动跨版本迁移。

## 运行结构

src/plugin/adapter/native_adapter.cpp/h 提供稳定只读入口，使用 Windows PE/RTTI、SHA256 与有限 leaf getter 合同。
Camera_GetObject 不再读取 RVA_CAM_SLOT 或 OFF_CAM_OBJ2CAM，而经适配器取得已验证对象。
表/getter/根引用在启动及运行中恢复，不在业务侧预填这些地址；字段布局仍由经过审核的 profile 声明。
现有 C 业务与 C++17 适配器通过 C ABI 相接，不交换 CRT/游戏堆对象。

## 早期安全门和依赖

PluginThread 在 AchievementSource、成就UI、IAT、进程hook、命令服务、Effect/Trigger及固定全局槽读取之前完成映像身份判断。
现有未迁移模块只允许经过原有验证的精确 SHA；未知映像不进入旧业务初始化。
未知映像若提供经过审核且校验通过的摄像机 profile，可使用只读 API/监视；写入及旧注册器仍阻断。
carrier 自身的 CRT 语义探测和原导出转发不是这道业务门的一部分；不声称未知版本的载体/DLL依赖也已验收。

当前构建保留原摄像机写入，要求精确已知 SHA、绑定就绪、字段与原写入布局完全一致。
读取 profile 缺失/无效时，摄像机 Effect/写命令不注册，其他不依赖此布局的已知构建功能不被无故关闭。
未迁移构建上没有旧 game-console bridge，原生只读API/状态可用不等于 plugin_camera_read 游戏命令也可用。
进程拦截若只装好部分 A/W 路径，会关闭拦截行为并标紫；不改变正常完整安装路径。

## 本地资料

位置：游戏根目录下 hoi4plugins/bindings/<完整小写SHA256>.profile。UTF-8无BOM/ASCII，每行key=value，无重复/未知key。
固定 schema=1、read_contract=leaf_rtti_v1、image_sha256 必须匹配实际文件，runtime_read 为0或1。
camera_pointer / height / minimum / maximum 是有界对齐的字段偏移，不接受任意函数地址、脚本或旧模块放行开关。
八个key均必需；示例见仓库 bindings 下当前构建资料。runtime_read=0 只表明不批准运行时使用。
仅启动加载；改文件不能热替换已发布绑定。局部资料是受信任的人工审核结果，格式合法不能代替布局语义审核。
当前旧模块的 SHA 白名单仍编译在代码中，不能通过配置把任意构建的旧 RVA 功能全部打开。

工具 prepare_native_camera_profile.py 为已验证当前构建生成可用资料；其他构建生成 candidates 下禁用草稿，不能误当成审核通过。
未知布局/getter形式改变时应拒绝并补充迁移证据，而不是盲目照抄当前偏移。

## 只读API与对象合同

导出 Hoi4Plugin_ReadCameraV1，参数 NativeCameraSnapshot 的size/version须正确；当前版本1。
成功返回1，含目标height、minimum/maximum及诊断对象地址；失败返回0及状态。对象地址不持有所有权，不应缓存或用于未知构建写入。
读取验证精确类名、COL/self/主表、loaded COL、虚槽指向及getter字节，合并同对象多根和同函数虚槽别名，拒绝真正歧义。
getter只接受已实现的无副作用leaf读取形式；适配器并不执行游戏getter，不需要外部线程伪装成游戏线程。
公开读取全扫描可写映像根；已知构建内部旧写路径缓存根位置，并逐次复核类型/指针/值及定期全扫描，不缓存裸对象无条件复用。
调用前后检查不等于游戏线程原子快照，不能排除ABA。初始绑定通过发布屏障后才供API读取。
只读 API 拒绝 NaN/异常范围；已知写路径允许已验证对象进入原有纠正逻辑，避免把修复 NaN/过渡值的旧能力一起禁用。
没有热卸载承诺，监视线程和绑定保持进程生命期。

已知构建增加 plugin_camera_read，只读、不改变游戏时间。主菜单返回 NOT_IN_MAP，成功显示 READY_READ_ONLY 及数值。
该命令沿用现有执行/单人权限规则，没有新增多人指令放行。

## 状态与颜色

游戏根目录 hoi4plugin_function_log.log 每次新版插件启动重建，后续追加本次状态变化，不按帧输出。
[function:available] 为绿色（前景10），[function:unavailable] 为紫色（前景13），保留背景色。
外部控制台新增第四日志源 FUNCTION 和 /filter function。未知构建以 --read-only 打开，命令与补全不访问旧 bridge。
兼容 -no-plugin-console；仍可直接读取独立状态文件。
camera.binding/identity 是合同及绑定状态；registration/commands 是精确注册/安装状态；camera.read/write 是场景相关能力，主菜单可暂时标紫。
未知/缺失/歧义及初始化失败均给状态原因，不把“有候选地址”标成运行时可用。
