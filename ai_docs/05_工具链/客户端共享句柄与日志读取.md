# 客户端共享句柄与日志读取

2026-10-14，第十七批，真实复用catalog与tail的owned kernel handle机制。

## 私有模块

`src/debug_console/owned_kernel_handle.h`持有 `ClientResource::KernelHandleCloser/OwnedHandle`。
deleter的原有NULL/INVALID_HANDLE_VALUE规则不变；标准unique_ptr负责唯一所有权及栈展开释放。
目录查询和 `Tail::Poll`共同使用，不再在某个实现文件里隐藏另一份通用清理规则。
只针对调用者创建的process、snapshot和本次日志file；借用标准句柄、全局game/pipe/mutex/线程未迁移。

## Tail::Poll保留的行为

打开权限、读写删除共享、OPEN_EXISTING、普通文件flags不变。
正常文件在原位置reset；信息/尺寸/seek失败及C++异常自动关闭，不改变错误返回或新增catch。
identity/volume变化、尺寸缩小、sentinel不匹配仍触发原重置提示。
offset、partial、sentinel、dropping以及64KB读取、256行上限、UTF-8长行分段算法不变。
重置提示也计入256行预算：批次夹具首轮255数据行+提示，offset510，第二轮45数据行到offset600。

异常仍向外传播，Tail对象不新增事务回滚；例如partial扩容失败前已写入的字符仍可能保留，offset也按原时点更新。
本批不能推导“内存不足后重试绝不重复日志”或“客户端绝不会退出”。修正的是owned handle泄漏。
