# 替换与验证

## 替换步骤

    1. 备份原版:  tbb.dll  ->  tbb_real.dll
    2. 放入我们的 tbb.dll (产物)
    3. 编译器生成的 tbb.lib / carrier_exp.exp 不需要拷贝

## 验证游戏功能未受影响

替换后**游戏能正常启动到主菜单**，就说明 100+ 导出的转发是通的
—— 游戏导入表里每一个函数都必须解析成功，缺一个就起不来。

日志里的证据：

    [case1] game-root tbb.dll loaded by game
            main=00007FF6F3CC0000 (hoi4.exe)
            carrier path = ...\Hearts of Iron IV\tbb.dll

## 验证插件被加载

    [case2] plugin loaded: ...\hoi4_mod_plugin.dll
            base=00007FFDDDBD0000   name=hoi4_mod_plugin.dll
    [plugin] thread start, pid=53184

## 多载体共存

玩家可能装了多个载体（如 winmm.dll、version.dll 之类同款方案）。
引导器用一个命名互斥体保证**只有第一个进来的负责加载插件**：

    [carrier] another carrier holds lock

## 反面记录：mod 目录方案（已否决）

早期尝试把插件放 mod 目录，结论是**不可行**：

| 原因 | 说明 |
|---|---|
| mod 目录不在 DLL 搜索路径 | 只能自己主动"扫"，多一层耦合 |
| 方案绑死在"用户的 mod 在哪、叫什么" | 换一个 mod 就要改代码 |

相关探索记录原在 flirt/loader/（mod目录exe启动探索、mod目录加载DLL探索）。
**该目录已不存在**（相关内容已迁移到 test/），结论并入本文档。
