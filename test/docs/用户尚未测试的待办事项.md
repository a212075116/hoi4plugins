# 用户尚未测试的待办事项

2026-10-12创建。只收录当前需要用户在真实游戏画面、实际操作体验或真人多端环境中确认的事项。
不把可由工具执行的源码检查、原生夹具、日志核对、资源监测加入这个列表。未来工具条件变化后，应重新划分，不永久宣称视觉只能由人操作。
已有数值/恢复/字段验证不替代目视；用户已确认解决的原有UI颜色问题不重新列为未解决。

## U01：新增数值与Trigger工具提示的真实显示

- [ ] 游戏内实际悬停scalar64/typed Trigger/Array64相关条件与效果，确认长数值完整显示，例如12345678901.125、-0.00001。
- [ ] 确认没有文字截断、遮挡、乱码、异常换行，中文结果词与比较符号能读懂。
- [ ] 比较成立/不成立以及NOT反转时，屏幕上的结果、颜色和文字对应正确；这不是重测已解决的旧颜色缺陷。
- [ ] 使用自己的分辨率、UI缩放与实际mod界面观察，不能只凭内存字符串判断布局。

前提：使用准备发布的本地化资源；Camera test之类临时测试标签不构成正式中文视觉通过。
回传：截图/短录像、游戏/插件版本、语言、分辨率、UI缩放、触发事件或脚本片段；避免含个人信息的存档/日志。
通过：实际画面完整、可读，正反条件结果与预期相符。此项仍待用户确认，不因为原生tooltip4/4或摄像机事件9/9自动勾选。

## U02：摄像机实际画面与手动交互体验

- [ ] 实际观察控制台和Effect设置/增加高度的画面是否同样平滑、无突然跳变或卡住。
- [ ] 提高下限/降低上限时，观察画面与限制是否协调，连续触发后仍可正常缩放。
- [ ] 用鼠标滚轮、拖动地图等真实操作检查是否出现输入被打断、镜头不跟随、画面与记录目标明显不一致。

使用独立测试存档，记录原高度/上下限并在测试后恢复；不要直接拿正式战役试极端值。
回传：短录像及对应操作顺序，注明哪一步开始不符合预期。字段目标值通过不代表用户看到的过渡体验已经通过。

## U03：未来真实多人使用体验（有人员与环境时再测）

- [ ] 用户组织真实主机和客户端，以相同插件/mod/本地化版本同时观察操作、提示与显示是否一致。
- [ ] 由参与者实际断线、重连和共同加载配对测试存档，描述不同电脑上的玩家可见结果。

只把真人环境协调与实际体验放在此处；数值/日志/校验和的自动比较仍可交给测试工具，不转嫁给用户。
此项不阻塞当前单人功能交付，也不代表多人已受支持；没有多人环境时保持未勾选。

## U04：外部调试控制台的实际显示与输入体验

- [ ] 在自己的字体、DPI和窗口宽度下观察三类来源标签、中文日志、换行及长命令输入是否可读。
- [ ] 一边刷日志一边输入、使用方向键和历史，确认中文宽字符光标、输入行重绘不会造成主观操作困难。
- [ ] 实际点击终端关闭按钮，确认游戏体验不受影响；从游戏`debugconsole`或EXE重开后窗口正常。
- [ ] 观察窗口聚焦、切回游戏和调整窗口大小是否符合自己的使用习惯。

这只记录视觉/真实交互；进程终止隔离、重开、协议边界、堆释放和日志读取均可自动测试，不交给用户代做。
回传：问题截图或短录像、具体输入、字体/DPI和窗口大小。当前未进行GUI视觉认证。

## 不属于本列表的事项

- 资源增长：用户接受当前约283MiB增量，超过2GB增长才作严重问题；监测与归因可自动执行，不是用户专属测试。
- 掉电/硬件缓存持久性：用户明确不要求解决这种超极端条件，不列为必须验收或让用户拔电测试。
- 外部控制台自动检查见[专用测试入口](external_console.md)；仅主观显示/输入体验列在U04。
